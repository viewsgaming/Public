Installation Guide

Quick 4-step installation for all platforms:

1

Check Java and Loader

Make sure you have NeoForge 1.21.1 installed. Requires Java 21 strictly.

2

Extract directly to Game Directory

The zip already includes the mods/ folder inside. Extract it straight into your Minecraft root folder:

Windows: %appdata%\.minecraft\
Prism / CurseForge: Instance Folder → .minecraft
PojavLauncher: /sdcard/Android/data/net.kdt.pojavlaunch/files/.minecraft/
3

Clean Old Mods (Optional)

If upgrading from an older version, clear any older duplicated .jar files inside your existing mods/ folder before launching.

4

Memory Allocation

Allocate 4GB to 6GB (4096MB+) of RAM in launcher settings to prevent chunk stuttering.

Troubleshooting

Game crashes with Exit Code 1?

Check if your launcher profile is set to Java 21 and the modloader is NeoForge (not legacy Forge).

OptiFine support?

OptiFine is unsupported and crashes Sodium. Use Iris for shader configurations instead.
