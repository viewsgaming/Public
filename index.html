How to Install This on Your Launcher

Takes about 2 minutes. Follow these 4 steps in order:

1

Check Your Java & Loader Version

Ensure you have NeoForge 1.21.1 installed (NOT Fabric, NOT normal Forge). This version strictly requires Java 21 to boot.

2

Extract the Zip File

Don't just drag the entire .zip into your mods folder. Extract it first with 7-Zip, WinRAR, or ZArchiver. You should see separate .jar files inside.

3

Move into Your mods/ Directory

Copy every extracted .jar into your Minecraft profile's mods folder:

Windows: %appdata%\.minecraft\mods
Prism / CurseForge: Open Instance → Click "Open Folder" → mods
PojavLauncher: /sdcard/Android/data/net.kdt.pojavlaunch/files/.minecraft/mods
4

Set Your Memory to 4GB – 6GB

Because Create and Terralith generate huge structures, give the game at least 4096 MB of RAM in your launcher settings to stop lag spikes.

Having Trouble?

Game crashes on startup with "Exit Code 1"?

You probably launched with standard Forge or Fabric instead of NeoForge, or your launcher is set to Java 17 instead of Java 21.

Can I add my own mods (like OptiFine)?

Do not install OptiFine—it breaks Create and Sodium immediately. Sodium and Iris are already built-in for better performance and shader support.
