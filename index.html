Installation Steps

1
Download the NeoForge_1.21.1_Full_Player_Pack.zip file using the button above.
2
Extract the contents of the downloaded .zip file using an archive manager.
3
Copy all extracted .jar files into your launcher profile's mods directory.
4
Launch Minecraft using the NeoForge 1.21.1 loader and connect to the server IP.
